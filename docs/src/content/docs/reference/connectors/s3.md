`connectors/s3`, package `cloacina-connector-s3`. A source that lists and
reads NDJSON objects from an S3-compatible store (AWS S3, MinIO) over HTTP.
Each non-empty line of an object is a record. Moved from weir
(CLOACINA-T-0985).

## Config

| Key | Meaning |
|---|---|
| `endpoint` | `https://s3.amazonaws.com`, `http://minio:9000`. Required. |
| `bucket` | Required. |
| `prefix` | Only keys under it. Default: the whole bucket. |
| `max_keys` | The listing page size. Default: S3's 1000. Listings follow continuation tokens either way. |

**Grant:** `{"http": ["<endpoint host>"]}`.

**Credential:** `aws_sigv4`, with `region` and a secret holding
`access_key_id` and `secret_access_key`. The guest sends unsigned requests;
the host signs them. See [Credential Injection](../../../explanation/primitives/sync/credentials/).

## Source

| Mode | How it reads |
|---|---|
| Full refresh | Every object under the prefix. |
| Incremental | Objects whose key sorts after the cursor (`start-after`). Append-only key schemes, such as date partitions or ULIDs, resume cleanly. The cursor is the last key read. |

`discover` offers one stream, `objects`. `check` lists one key, so a wrong
bucket or key fails it. There is no destination.

## Testing

MinIO runs under the compose profile `minio`:

```bash
docker compose -f .angreal/docker-compose.yaml --profile minio up -d --wait minio
cargo test -p cloacina-sync --test s3_connector -- --ignored
```
