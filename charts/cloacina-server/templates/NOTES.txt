Image:    {{ include "cloacina-server.image" . }}
Release:  {{ .Release.Name }} (namespace: {{ .Release.Namespace }})

1. Wait for the pod to become ready:

    kubectl --namespace {{ .Release.Namespace }} \
      rollout status deployment/{{ include "cloacina-server.fullname" . }}

2. Read the bootstrap API key. The pod that logged "Bootstrap admin key
   written" holds it in a file on an emptyDir, lost when the pod restarts:

    kubectl --namespace {{ .Release.Namespace }} \
      exec <pod> -- cat /home/cloacina/.cloacina/bootstrap-key

   Or pin one ahead of time via `--set apiKeySecretRef.name=...`.
   Then make a second key with `cloacinactl key create <name> --platform-admin`
   and revoke the bootstrap key.

{{- if .Values.ingress.enabled }}

3. Ingress is enabled — your server is reachable at:
{{- range .Values.ingress.hosts }}
    http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}
{{- else }}

3. Ingress is disabled. To reach the server from your laptop:

    kubectl --namespace {{ .Release.Namespace }} \
      port-forward svc/{{ include "cloacina-server.fullname" . }} 8080:{{ .Values.service.port }}

   Then `curl http://localhost:8080/v1/health` should return 200.
{{- end }}

{{- if .Values.metrics.enabled }}

4. /metrics is not on the API port. It is on port {{ .Values.metrics.port }}, Service
   {{ include "cloacina-server.fullname" . }}-metrics.
{{- if .Values.metrics.networkPolicy.enabled }}
{{- if .Values.metrics.networkPolicy.from }}
   A NetworkPolicy opens that port only to the peers in
   `metrics.networkPolicy.from`.
{{- else }}
   A NetworkPolicy closes that port to every pod: `metrics.networkPolicy.from`
   is empty. List your Prometheus there to let it scrape.
{{- end }}
{{- end }}
{{- else }}

4. WARNING: metrics.enabled=false. /metrics is on the API port with no
   authentication: every client that can reach the API, each tenant's agents
   included, can read every tenant's names in the metric labels.
{{- end }}
